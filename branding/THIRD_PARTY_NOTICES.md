# Avisos de terceros

**The Ultimate Whiteboard** es una bifurcación (fork) de [Excalidraw](https://github.com/excalidraw/excalidraw) y usa software libre de terceros. Estos son los principales; la lista completa de dependencias y sus licencias está en `yarn.lock` y en el `package.json` de cada paquete.

| Componente | Uso | Licencia |
| --- | --- | --- |
| [Excalidraw](https://github.com/excalidraw/excalidraw) © 2020 Excalidraw y colaboradores | Editor de pizarra (base de este proyecto) | MIT |
| [Electron](https://www.electronjs.org/) | Aplicación de escritorio | MIT |
| [electron-builder](https://www.electron.build/) / electron-updater | Instalador y actualizaciones | MIT |
| [React](https://react.dev/) | Interfaz | MIT |
| [KaTeX](https://katex.org/) | Fórmulas LaTeX (incluye sus tipografías, SIL OFL 1.1) | MIT / OFL-1.1 |
| [roughjs](https://roughjs.com/) | Trazos tipo boceto | MIT |
| [perfect-freehand](https://github.com/steveruizok/perfect-freehand) | Trazos de lápiz | MIT |
| Tipografías Excalifont, Nunito, Lilita One, Comic Shanns, Liberation Sans, Assistant, Cascadia | Textos del editor | SIL OFL 1.1 y similares (ver `packages/excalidraw/fonts`) |

El texto completo de la licencia MIT de Excalidraw está en el archivo `LICENSE` (incluido junto a esta aplicación). Este proyecto no está afiliado ni respaldado por Excalidraw.
